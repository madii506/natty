# NATTY

He is natty. He has always been natty. Ask him again and he will tell you again.

A one-page site for the NATTY coin. Everything on it is drawn rather than
borrowed: the intro, the avatar generator and the six gallery scenes are all the
same figure, from the same bezier grammar, at different sizes.

- `index.html` — the whole site. No build step, no framework, no dependencies.
  The intro is a canvas animation, not a video file.
- `assets/` — two fonts, the banner, the favicons.
- `assets/memes/` — six scenes, no captions. The joke belongs in the post.
- `vercel.json` — asset cache headers, `nosniff`, `no-referrer`.

No token exists yet. When one does, its address goes on the page and in the
pinned post at the same moment; anyone posting one before that is scamming you.
